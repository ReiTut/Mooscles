# Mooscles 1.5.9 / Build 32

- New quick-workout sets start with the weight and reps from the same qualifying personal record. Bodyweight-only records keep a blank load field. Planned **Follow the record** sets still follow their own linked records.
- The active workout keeps previous results, weight, reps, and checks aligned on more phone layouts, with room for decimal weights. Long exercise names use up to two lines in the rest timer.
- Shared workout cards credit genuine improvements at the exercise's record weight or a heavier eligible set. The preview and exported images use the same Records list and total, including on multi-page exports. Repetition records at individual loads remain in workout history.

This full release distributes the Android debug APK signed with the original Mooscles certificate. Android may ask you to approve the update.
