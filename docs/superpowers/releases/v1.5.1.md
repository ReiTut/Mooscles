# Mooscles 1.5.1 / Build 22

Full GitHub Release, marked Latest. The attached APK is the existing **debug build**, signed with Mooscles' original distribution certificate. GitHub release classification does not change its build type.

## Changes

- Choose **System default**, **English**, or **Português (Brasil)** in Settings. System default follows your device; explicit selections persist across restarts and synchronize with Android 13+ per-app language settings.
- Existing history, workout-detail, picker, dialog and sharing-preview labels now follow the selected language. Custom routine and exercise names remain as written.
- Language switching preserves in-progress set drafts, focus, navigation and timer continuity. Exact saved and pending weights are retained when decimal separators change, including pound displays.
- New white-M/green-barbell launcher artwork, with adaptive, round, themed and density-specific assets. Notification icons remain unchanged.
- Includes host-test portability corrections for Windows; these do not change application data or runtime behavior.

Phase 5/5B remains paused. Existing Phase 5A functionality is preserved. This release makes no general startup or scrolling-performance claim.

## Compatibility and update delivery

Application ID remains `com.mooscles`, minimum Android version remains 8.0/API 26, database schema remains 6, and existing signing identity is retained. Version code 22 is above the previous stable Build 21 and all known prereleases and connected test installations inspected during preparation.

The APK, `update.json`, and APK SHA-256 file are release assets. Stable-channel updaters can discover Build 22 using its metadata; enabling prereleases is unnecessary. Automatic download depends on saved preferences, and Android may require installation approval. No existing release or tag is replaced.

## Verification and limits

- Reused the [70 passing focused checks and Android 15 emulator observations](../reports/2026-11-01-language-launcher-verification.md) for the unchanged implementation. These cover language ownership, persistence, supported/unsupported system-language behavior, localized labels, drafts, exact weights and icon resources.
- Fresh release preparation passed 25 focused updater checks (`ReleaseClientTest` 15, `ApkVerifierTest` 10), a clean debug build, lint (0 errors, 21 warnings), and APK/font/icon budgets. The APK's package, version and original signer were verified; metadata was generated from those final bytes. Publication includes independent download/hash verification.
- Existing emulator evidence includes a focused `22.` draft retained during EN→PT switching while rest continued from 1:58 to 1:55, and selection/active-session persistence after relaunch. These recordings were not repeated solely for the version bump.
- Some existing updater/backup diagnostic messages remain English. Older Android language behavior was checked with Robolectric API 28; physical-phone language behavior, TalkBack speech, OEM launcher masks and iPhone behavior were not verified. Update discovery is distinct from installation; this publication does not claim a physical-device upgrade.
