# Mooscles 1.5.4 / Build 26

The Android download uses the existing debug build and original distribution signing certificate. The intended channel is a full GitHub Release marked Latest.

## Changes

- Browse completed workouts in a monthly calendar or a searchable list. Filter by routine, exercise, date or beaten record.
- See overall training progress by period, including workout frequency, volume, muscle distribution, most-performed exercises and accessible chart tables.
- Read and edit saved workouts in the redesigned detail screen. Exact set values, rest durations and the PR count beside Sets are preserved.
- Preview shared workout cards in a redesigned screen. The existing artwork, PNG layout, multi-page exports and Android share destinations remain available.

## Compatibility and verification

The APK uses `com.mooscles`, requires Android 8.0 or newer and keeps Room schema 6, the original signer and the updater metadata format. Build 26 is newer than stable Build 25. The isolated Phase 5B offline upgrade retained routines, history, exact set values, preferences and the running timer.

In a repeated comparison on one Android 15 phone, the History Progress muscle-map layer reduced janky frames from 7.24% to 1.39% while scrolling. The test used an optimized, isolated build and synthetic history. Occasional slow frames remain when the map comes back into view. The live unit-switch timing goal remains open, and first-visible-frame and active-workout rendering timings remain unmeasured.
