# Mooscles 1.5.11 / Build 34

- Records are counted per exercise. Reps records now count only at the heaviest load you have used for an exercise (the least assistance for assisted exercises), so a set at a lighter, untried weight no longer shows up as a record.
- An exercise's first session counts as one PR: a load record, or a reps record for bodyweight and assisted exercises. The separate "First" records, their badge, filter and summary section are gone.
- During a workout, the PR badge and message still appear only when you beat an earlier record.
- Your saved workouts are unchanged; records are recalculated from them.

This full release distributes the Android debug APK signed with the original Mooscles certificate. Android may ask you to approve the update.
