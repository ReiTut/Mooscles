# Mooscles 1.5.2 / Build 23

Full GitHub Release, marked Latest. The APK remains the existing **debug build**, signed with Mooscles' original distribution certificate; GitHub release classification does not change the APK build type.

## Changes

- Replaces the shared-workout header logo with the supplied white/lime Mooscles wordmark, preserving its lettering and barbell details.
- The preview and every exported PNG page use the same new artwork, loaded and cached outside drawing.
- Keeps the existing header allocation, workout content, dates, duration, sets, volume, PRs, translations, exercise order and pagination.
- Keeps existing PNG dimensions, file handling, FileProvider and sharing destinations. The launcher icon is unchanged.

The source artwork is only 260×72 pixels, so it may appear slightly soft when enlarged. No general performance improvement or Phase 5B completion is claimed. Phase 5/5B remains paused.

## Compatibility and delivery

Application ID `com.mooscles`, database schema 6, minimum API 26 and the original signing identity are retained. Version code 23 is above the previous distributed Build 22. No workout-storage format or updater contract changed.

The APK, `update.json` and checksum file are release assets. Existing stable-channel updaters can discover Build 23 without enabling prereleases. Download behavior depends on saved preferences; Android may require installation approval. No previous release or tag is replaced.

## Verification and limits

- Reuses [22 passing host tests and 6 passing Android 15 emulator tests](../reports/2026-11-02-share-wordmark-verification.md), including source-art assertions on every page, English/Portuguese cards, long names, unchanged page counts, export/preview/intent behavior and real chooser inspection. No recipient was selected and nothing was sent.
- Implementation evidence includes an in-place emulator install without clearing storage and unchanged history totals of 208 workouts, 9,608 completed sets and 72 exercise PRs. It is not a physical-phone upgrade claim.
- Fresh release preparation passed a clean debug build, lint (0 errors, 21 warnings), the 169-file design-token check and APK/font/icon budgets. Package/version/original signer were verified, and metadata was generated from the exact final bytes. Published assets are downloaded independently for comparison.
- No new device recording/installation is required for the version-only change. Physical-phone/iPhone installation and WhatsApp recipient UI remain unverified. Existing preview downsampling and unrelated English diagnostic messages are unchanged.
