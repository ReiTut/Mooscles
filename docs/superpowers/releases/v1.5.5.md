# Mooscles 1.5.5 · Build 27

Build 27 was an unpublished candidate. [Build 28](v1.5.6.md) carries this update with corrected History navigation test synchronization.

- Open **History → Progress → Weekly** to see this week's working sets by muscle. The current week shows totals to date. Use **Previous week** and **Next week** to browse saved workouts by calendar week.
- The muscle breakdown counts one set for each primary muscle and half a set for each secondary muscle. It excludes warm-ups and incomplete sets. Weight volume has its own total.
- Weekly is available in English and Brazilian Portuguese. The week controls stack at larger text sizes.
- The project and CI now target Android while retaining the shared Kotlin and Compose modules.

This full release distributes the **Android debug APK** with the original Mooscles signing certificate. It is an update for existing installations. Android may ask you to approve installation.

The Weekly screens and calculations passed focused Android host and emulator checks. [Design and verification](../plans/2026-11-15-weekly-muscle-sets.md) · [Release checks](../../../VERIFICATION.md)
