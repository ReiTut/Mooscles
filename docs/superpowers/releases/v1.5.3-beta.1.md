# Mooscles 1.5.3-beta.1 — routine-startup preparation and entry visibility

Optional prerelease, versionName **1.5.3-beta.1**, versionCode **24**. The distributed
APK is the existing **debug build**, signed with the original debug distribution
certificate. Stable v1.5.2 / Build 23 remains Latest.

## Changes

- Skip historical PR calculations until the active workout contains an eligible,
  valid completed working set. Warm-up and unfinished sets do not trigger the work;
  bodyweight and assisted exercise records remain supported.
- Remove only the forward workout-entry fade, so the workout no longer fades over
  Train. Back and unrelated navigation behavior remain unchanged.
- Add two focused presenter regressions and update the corresponding CI test minima.

Phone evidence shows reduced PR preparation CPU and no extra detected opacity ramp
in two final editor recordings. It does **not** show a consistent improvement in
overall editor-ready time or first scrolling. Initial layout and occasional graphics
stalls remain. This release preserves current skeleton placeholders; it does not
restore the old literal “Starting workout…” overlay. No general stutter fix or
Phase 5B completion is claimed; Phase 5/5B remains paused.

## Compatibility and update channel

Application ID `com.mooscles`, schema 6, minimum API 26 and the original signer are
retained. Build 24 exceeds the inspected published and connected test builds (23 or
lower). No saved workout, preference, timer or updater format changes.

Enable **Include prereleases** in Settings to discover this optional update. The
stable channel continues to offer v1.5.2. Downloads respect saved preferences and
installation waits until no workout/rest timer is active. Android may require
installation approval. No previous release or tag is replaced.

The versioned APK, `update.json` and adjacent `.sha256` file are release assets,
not source files. Stable main is not merged merely to publish this beta.

## Verification and limits

- Reuses [70 passing focused host tests and physical-phone observations](../reports/2026-11-03-routine-startup-latency.md)
  from the unchanged implementation: PR eligibility, bodyweight/assistance, Start,
  duplicate protection, failure/cancellation, navigation/discard, drafts, exact valid
  values, completion, timer continuity and reopening.
- Performance evidence used an optimized/profileable build on an Android 15 Redmi
  Note 12, with 8 exercises / 32 sets and 200 historical workouts. Frame commits are
  proxies; earliest possible interactivity and synchronized absolute optical timing
  remain unmeasured. Trace quality and shader-cache limitations are documented.
- Fresh version preparation checks updater metadata/channel and signer policy,
  debug packaging, APK budget and package/version/original signer. Final metadata
  is generated from the exact APK; public downloads and update discovery are
  verified separately before delivery is reported complete.
- The final version-only APK is not installed over the user's production app for
  publication. Discovery verification is not installation verification. No storage
  clearing, uninstall, signing substitution, new performance recordings or unrelated
  local suites are used. Required repository CI is completed separately.
