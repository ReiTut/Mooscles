# Mooscles 1.5.7 · Build 29

- In **Train → routine menu → Edit**, swipe left to remove a planned set. **Undo** restores it to its original position.
- **Follow the record** now updates each planned set independently when you finish a workout. If set 1 improves from **20 kg × 7** to **22 kg × 6**, set 1 takes the new target and set 2 keeps its own. The editor and your next workout show the saved targets.
- Existing routine targets and workout history carry forward through an additive Room migration. Older workouts and ad hoc sets have no planned-set link, so their results leave existing targets in place. Backups from older builds can still be imported.

This full release distributes the **Android debug APK** with the original Mooscles signing certificate. Android may ask you to approve installation.
