# Mooscles 1.5.10 / Build 33

- Starting a routine fills each set's weight and reps with the set shown in its Previous column, for every exercise and every set, including **Follow the record** sets. A set with no Previous set keeps its routine target. Routine targets themselves are not changed.
- The same applies to quick workouts: an exercise added to a workout starts from its Previous sets (or its record when there is no Previous set), and **Add set** copies the Previous set at that position when there is one.
- The rest timer shows the exercise name on its own line across the top of the dock, without the "Rest ·" prefix, so long names are no longer cut. The expanded timer keeps the full title.

This full release distributes the Android debug APK signed with the original Mooscles certificate. Android may ask you to approve the update.
