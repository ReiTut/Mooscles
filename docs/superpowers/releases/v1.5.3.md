# Mooscles 1.5.3 / Build 25

Full GitHub Release, marked Latest. Android APK uses the existing debug build and original distribution signing certificate.

## Changes

- Add **PRs beside Sets** to the completed-workout summary, saved workout detail and shared workout header. The actual preview and every exported PNG page show the same workout-wide total, including zero.
- Count each distinct exercise variation/convention with a first or beaten record once. Multiple record types or repeated record-setting sets do not inflate the total. Existing PR eligibility is unchanged.
- Add English and Portuguese accessible descriptions and responsive statistics. Wide share headers reflow while keeping Sets and PRs together where they fit; larger screen fonts use the existing accessible single-column approach.
- Include the previous beta's startup changes: skip historical PR calculations until an active workout has an eligible completed working set, and remove the forward workout-entry fade. Back navigation and skeleton placeholders remain intact.

Prior phone measurements show reduced PR-preparation CPU, but do not establish consistently shorter overall startup or smoother first scrolling. This release makes no general stutter-fix claim. Some existing updater/backup diagnostic messages remain English. Phase 5/5B stays paused and existing Phase 5A features remain available.

## Compatibility and delivery

- Application ID `com.mooscles`, minimum Android API 26, schema 6 and original signing identity are retained. No workout, preference, timer or updater format changes.
- Actual versionName **1.5.3**, versionCode **25**, higher than stable Build 23 and beta Build 24.
- Both stable and beta installations can discover this full release with **Include prereleases disabled**. Android may require installation approval. Discovery checks do not prove installation.
- Assets are the freshly built `Mooscles-v1.5.3-debug.apk`, generated `update.json` and APK checksum. Previous beta/release assets and tags remain intact.
- A verified PC-only source/APK/prerelease backup was created outside the project and is excluded from GitHub.
