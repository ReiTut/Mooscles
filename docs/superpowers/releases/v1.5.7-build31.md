# Mooscles 1.5.7 · Build 31 recovery

This release restores the app behavior from **Mooscles 1.5.7 / Build 29**, including the original shared workout Records list and PR count. The version name is **1.5.7** and the installed build is **31**, so Android can install it as an update over Build 30. Existing routines, workouts, and preferences use the same data formats.

This full release distributes the **Android debug APK** with the original Mooscles signing certificate. The in-app stable updater can discover it, and Android may ask you to approve installation.
