# Weekly muscle sets

The requested Weekly period appears before 4 weeks in History → Progress. It opens on the current calendar week. Previous and Next move one week at a time, with Next disabled on the current week. The header shows the selected week's full date range and calls the current totals Week to date. The period and week are saveable within the Progress segment.

The week starts on the existing regional first weekday and uses the local time zone. History assigns each saved workout to its local start date. Past weeks include all seven dates, and the current week includes dates through today.

The view lists all trained muscles in descending order of weighted working sets. It credits each primary muscle with one set and each secondary muscle with half a set, using the existing History rules for eligible sets, custom exercises and Full Body. The summary shows logged sets and weight volume as separate statistics. An empty week keeps the date and navigation controls visible.

The shared Progress index and query cache supply the totals from saved history. The feature uses the existing English and Brazilian Portuguese resources, saveable state and design-system components.
